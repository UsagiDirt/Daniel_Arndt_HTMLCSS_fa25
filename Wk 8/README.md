# Wk8: Featured Products

A small HTML and CSS project that presents three featured products as cards:

- Astro A50 X wireless gaming headset
- Split hardwood skateboard
- Smart water bottle

## Project files

- `index.html` contains the page structure and product descriptions.
- `styles.css` sets the page colors and typography, lays out the product cards, and adds a hover effect.

## View the page

Open `index.html` in a web browser. The page loads `styles.css` from the same folder.
