# Wk9: Midterm Project - Personal Brand Website

A three-page personal brand website with a cherry blossom color theme. The site lives in the `midterm_project` folder.

## Project files

- `midterm_project/index.html` is the homepage. It introduces me and shows My Skills, What I'm Into, and Current Focus sections.
- `midterm_project/portfolio.html` shows six projects, each in its own `<article>`.
- `midterm_project/contact.html` has a `mailto:` email link and my GitHub profile.
- `midterm_project/styles.css` styles all three pages.
- `midterm_project/images/` holds the homepage photo.
