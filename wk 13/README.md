# Wk 13: Responsive Dashboard with Flexbox

This project is a sample peptide skincare sales dashboard. The sales and inventory numbers are fictional, and the health-topic cards are for information only.

## Open the project

Open [`week13_assignment/index.html`](week13_assignment/index.html) in a web browser. The HTML and CSS files are in the same folder, so no setup or installation is needed.

## What to try

- **Resize the browser:** The sidebar and main content sit side by side on wider screens. On smaller screens, the sidebar moves above the content and the cards wrap.
- **Hover over a card:** It grows slightly, moves up, and casts a stronger shadow.
- **Look at the last card on a wide screen:** The Weight Loss card sits at the bottom of its row using `align-self: flex-end`.
- **Try the sidebar links:** Each link jumps to its section. National Diabetes Month jumps to the note inside the Diabetes card.
