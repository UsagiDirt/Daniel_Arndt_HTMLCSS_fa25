About This Website

This website was created as part of my web design coursework. I am learning how to structure pages with HTML, create navigation with hyperlinks, and improve the appearance of pages with CSS.

I am interested in building websites that are organized, easy to understand, and useful for visitors. Creating multiple pages helps me practice how files connect through relative paths. It also helps me understand why consistent navigation is important for a website.

As I continue learning, I will practice using semantic HTML, accessible design choices, and professional CSS styling. This assignment focuses on linking pages together, linking to a specific part of a page, creating an email link, and safely opening an external website in a new browser tab.

A website should make it easy for a visitor to move between pages. A navigation menu gives the visitor a predictable way to return to the homepage or learn more about the person or organization represented by the site. Clear links and descriptive labels are an important part of a positive user experience.

The more I work with HTML and CSS, the more I understand that web design involves both technical skills and thoughtful organization. A small site can still be clear, visually consistent, and easy to use when its files, links, and styles are planned carefully.
